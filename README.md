# [ MDR ] MiniDeepResearch

Минималистичный CLI-агент для глубоких исследований на базе локальных LLM (Ollama) и поисковика SearXNG. Поддерживает итеративный поиск, уточняющие вопросы и генерацию структурированных технических отчетов.

## [ ! ] Быстрый старт

```bash
# Простой поиск
uv run mdr "как устроена память в LLM агентах"

# Глубокое исследование с загрузкой полных страниц (Deep Dive)
uv run mdr "методы реализации RAG на markdown файлах" -f -i 3 -m qwen3.5:4b

# Вывод в файл в формате Markdown
uv run mdr "сравнение векторных БД" --markdown -o research.md
```

## [ > ] Флаги конфигурации

| Флаг | Короткий | Дефолт | Описание |
| :--- | :--- | :--- | :--- |
| --model | -m | llama2:7b | Модель Ollama (рекомендуется qwen3.5:4b+) |
| --strategy | -t | multi_iter | Стратегии: iterative, parallel, multi_iter, evidence |
| --iterations | -i | 3 | Макс. кол-во итераций уточнения |
| --fetch | -f | False | [!] Загружать полный контент страниц (дает глубину) |
| --fetch-backend | | auto | Бэкенд загрузки: auto (requests + curl-фоллбек + зеркала), requests, curl |
| --num-ctx | | 32768 | Размер контекстного окна (Context Window) |
| --num-predict | | -1 | Макс. токенов генерации (-1 = неограниченно) |
| --timeout | | 300 | Таймаут запроса к LLM в секундах |
| --markdown | -md | False | Форматировать вывод как Markdown |
| --output | -o | None | Путь к файлу для сохранения результата |
| --search-url | -s | http://localhost:8080 | URL вашего инстанса SearXNG |

## [ i ] Советы по использованию

1. [ Глубина ]: Всегда используй флаг -f (--fetch). Без него агент видит только краткие сниппеты из поисковика.
2. [ Ресурс ]: На 16GB VRAM модель qwen3.5:9b с --num-ctx 32768 оптимальна по скорости и качеству.
3. [ Финал ]: В режиме multi_iter агент автоматически завершит работу, если информации достаточно.

uv run mdr "набор инструментов и скиллов агентов на базе ллм c бесконечным циклом. 2026" \
                    -m qwen3.5:9b \
                    --num-ctx 65536 \
                    --timeout 600 \
                    -t multi_iter \
                    -i 4 \
                    --num-predict 32768 \
                    -f \
                    --markdown -o tools.md
